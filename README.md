# Кабинет травника — прототип

Интерактивная «консультация»: специалист говорит, клиент отвечает кнопками и в конце получает предложение продукта и кнопку оплаты.

## Файлы
- `scenario.js` — **все тексты, кнопки, продукты, цены и ссылки**. Правится без знания кода.
- `avatar.js` — рисованный специалист (заглушка до съёмки).
- `app.js` — логика: ветки, озвучка, субтитры, окно покупки.
- `index.html`, `styles.css` — страница и оформление.

## Как заменить рисунок на настоящее видео
Добавьте реплике ссылку на ролик:
```js
hello: { video: "https://…/hello.mp4", say: "Здравствуйте! …", options: [ … ] }
```
Тогда вместо рисунка играет видео, а `say` идёт субтитрами. Реплики без `video` по-прежнему озвучивает синтезатор.

## Оплата
У каждого продукта в `scenario.js` есть поле `payUrl`. Вставьте туда платёжную ссылку Prodamus или ЮKassa. Пока поле пустое, после «оплаты» показывается демо-окно.

## Запуск на компьютере
```
python -m http.server 8123
```
и откройте http://localhost:8123

## Размещение на GitHub Pages
1. Создайте репозиторий и загрузите в него содержимое этой папки.
2. Settings → Pages → Deploy from a branch → `main` / root.
3. Через минуту сайт откроется по адресу `логин.github.io/репозиторий`.
